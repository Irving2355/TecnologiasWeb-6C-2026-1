# Practica-10-Base

Proyecto base para la práctica 10 de React.

## Tema de la práctica

Estado global en React usando Context API.

## Pasos para ejecutar

```bash
npm install
npm run dev
```

## Qué contiene esta base

- React + Vite
- React Router
- Rutas base
- Página de inicio
- Página de cursos
- Página de favoritos
- Página 404
- Datos locales de cursos
- Componente de tarjeta de curso
- Archivo preparado para Context API

## Qué se completará en clase

- `FavoritosContext.jsx`
- Envolver `App` con `FavoritosProvider`
- Conectar `Navbar` al contexto
- Conectar `TarjetaCurso` al contexto
- Mostrar favoritos en la página `Favoritos`
