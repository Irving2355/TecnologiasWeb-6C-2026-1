# Práctica 14-15: React + Node.js + Deploy

Proyecto full-stack para cubrir:

- Integración de React con Node.js
- API con Express: rutas, middleware y controladores
- Consumo de API desde React
- Variables de entorno
- Build del frontend
- Preparación para deploy del backend y frontend

## Estructura

```text
Practica-14-15-Completa/
├── backend/
└── frontend/
```

## Ejecutar backend

```bash
cd backend
npm install
npm run dev
```

Backend local:

```text
http://localhost:4000/api
```

## Ejecutar frontend

En otra terminal:

```bash
cd frontend
npm install
npm run dev
```

Frontend local:

```text
http://localhost:5173
```

## Variables de entorno

Backend: copiar `backend/.env.example` a `backend/.env`.

Frontend: copiar `frontend/.env.example` a `frontend/.env`.
